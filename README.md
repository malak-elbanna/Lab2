# Space Explorer CLI

This is a Node.js CLI app that fetches some space-related data from NASA API

## Features
- NASA Astronomy Picture of the Day 
- Real-time ISS location updates
- List of upcoming space launches

## Setup
```bash
git clone https://github.com/malak-elbanna/Lab2.git
npm install
```
